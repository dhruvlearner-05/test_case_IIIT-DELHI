# Demo narration

## Udyam Digital
This is Udyam Digital by team test case, IIIT Delhi. Our working prototype helps a small business choose connectivity, understand its quote, check documents and track activation. Everything shown uses the supplied fictional data.

## 1. Discover the business
The advisor captures business type, staff, locations, budget, existing connection and priority. Primary guidance supports English and Hindi. This recording uses offline rules. A server side Gen AI connection can be enabled with your local API key.

## 2. An editable, transparent quote
For a five person office, the catalogue recommends fibre, backup, email and security. The subtotal is three thousand one hundred eighteen rupees per month. Setup and assumed demo tax are separate. Removing backup changes the total, and adding it back restores the quote.

## 3. Consent and real local OCR
Uploads remain locked until consent. Our bundled OCR engine reads actual specimen images locally. K zero nine is a clean sample. We review the extracted fields before checking mock GST and Udyam registries. No document or identifier goes to the language model.

## 4. Verification and payment failure
The prototype checks active GST, names, full address, dates and ID expiry. The sample passes consistency checks. This is not statutory telecom KYC. We deliberately simulate a failed payment. No real money is charged.

## 5. Follow every order step
Retry keeps the same order reference. The tracker shows current steps and product status. Labelled controls simulate installation events, a delay and a revised estimate. A masked order survives refresh and expires after twenty four hours.

## 6. Exceptions get human review
The journey also needs a failure path. We now load K zero one. Its cancelled GST blocks checkout and gives a clear reason for review. Withdrawing consent erases the local session. The prototype never silently approves an uncertain case.

## A testable submission package
The package includes source code, twenty nine regression tests, a seven slide business case, architecture and a one page privacy note. Impact figures remain pilot targets. Configure your API key locally, verify the live AI indicator, then upload the code and submission files.
